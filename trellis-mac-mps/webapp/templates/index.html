TRELLIS Apple Silicon port

Image → 3D asset, generated locally on your Mac's GPU via Metal. No CUDA.

What's new in this port
  • Every CUDA-only piece of the original TRELLIS pipeline replaced with pure-PyTorch/MPS or hand-written Metal equivalents — runs natively on Apple Silicon, no CUDA/Linux required.
  • A tile-binned Metal rasterizer (bins triangles into screen-space tiles before rasterizing, the same technique nvdiffrast's own CUDA rasterizer uses) — 14–30x faster hole-filling and mesh rendering than a naive brute-force Metal kernel at real mesh scale.
  • Fixed a silent mesh-decimation bug (vtkQuadricDecimation would no-op on certain non-manifold meshes) that was letting undecimated, multi-hundred-thousand-face meshes slip through the rest of postprocessing.
  • This web UI and the cli.py command-line tool, both driving the same verified pipeline.
