# ============================================================
# Hunyuan3D 2.1 — dependencies for AMD ROCm (Linux and Windows)
#
# torch / torchvision / torchaudio are NOT listed here on purpose: the right
# wheel depends on the GPU architecture and, for gfx1151 (Strix Halo), has to
# come from the TheRock nightly index rather than pytorch.org. The installer
# scripts handle that and refuse to overwrite a torch that already works.
#
# Versions are ranges, not upstream's hard pins: pinning numpy==1.24.4 or
# transformers==4.46.0 against a torch 2.9 ROCm build breaks more than it fixes.
# ============================================================

#     call (HfFolder, cached_download).

# newer system-wide install without uninstalling anything.
