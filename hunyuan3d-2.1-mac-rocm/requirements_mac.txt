# ============================================================
# Hunyuan3D 2.1 — dependencies for macOS (Apple Silicon, MPS)
#
# torch / torchvision are NOT listed here: install.sh installs them first from
# the default index, because the MPS build is the plain PyPI wheel and the rest
# of this file must resolve against whatever torch that lands.
#
# This file covers BOTH pipelines. Texturing on Mac used to be listed as
# "CUDA only", which was never true — see docs/ROCM_TEXTURING_PLAN.md — so the
# paint-only packages (RealESRGAN, pymeshlab, pytorch-lightning, pybind11) are
# part of the normal install now rather than an afterthought.
# ============================================================

# Core ML
#
# The two upper bounds are load-bearing, not caution:
#   transformers 5.x is a major break and upstream targets 4.46 (it drives the
#     DINOv2 and CLIP conditioners directly).
#   huggingface_hub 1.x dropped APIs that diffusers 0.30 and hy3dshape still
#     call (HfFolder, cached_download).
